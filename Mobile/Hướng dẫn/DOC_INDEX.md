## 📱 Về Project QLTSTC Kiểm Kê

### Thông tin chung
- **Tên:** qltstc_kiemke
- **Platform:** Flutter/Dart
- **Target:** Android (Mobile)
- **State Management:** GetX
- **HTTP Client:** Dio

### Tính năng chính
- 🔐 Đăng nhập và xác thực
- 📱 Quét mã QR/Barcode tài sản
- 📋 Tạo và quản lý biên bản kiểm kê
- 📊 Biểu đồ thống kê tài sản
- 📷 Chụp ảnh tài sản
- 👥 Quản lý hội đồng kiểm kê
- 💾 Lưu trữ dữ liệu local

### Cấu trúc code
```
lib/
├── main.dart              # Entry point
├── constants/             # API URLs, Configs
├── models/                # Data models
├── modules/               # Feature modules
│   ├── bbkk/             # Biên bản kiểm kê
│   ├── login/            # Đăng nhập
│   └── mains/            # Trang chủ
├── services/             # API services
└── utils/                # Utilities, Widgets
```

### Dependencies chính
- `get` - State Management
- `dio` - HTTP requests
- `mobile_scanner` - QR/Barcode scanning
- `image_picker` - Chụp ảnh
- `shared_preferences` - Local storage
- `fl_chart`, `syncfusion_flutter_charts` - Biểu đồ
